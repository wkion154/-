K-IDOL ARCHIVE — Windows 실제 브라우저 접속/이미지 진단

이 ZIP은 완성된 검색 앱/EXE가 아니라, 사용자 Windows에서 Kpopping 접속과 이미지 후보를 확인하는 진단 도구입니다. 클라우드에서 테스트할 수 없는 부분을 확인합니다.

1. ZIP 전체를 압축 해제합니다.
2. Python 3.12(Python Launcher 포함)와 Microsoft Edge 또는 Google Chrome이 필요합니다.
3. START_CHECK.bat를 더블클릭합니다. 처음에는 인터넷으로 고정 Python 의존성을 설치합니다. API 결제나 계정 로그인은 필요하지 않습니다.
4. 이름을 입력합니다. 기본값은 장원영입니다.
5. 브라우저가 열리면 검색 결과를 확인합니다. 자동 검색창을 찾지 못하면 사이트에서 직접 검색합니다. 원하는 페이지에서 터미널로 돌아와 Enter를 누릅니다.
6. results 폴더에 생성되는 search-report.json을 이 대화에 첨부하세요. RESULT.html은 링크 목록을 로컬에서 읽는 보고서입니다.

접근 제한/robots 금지/로그인/CAPTCHA가 나오면 중단합니다. 개인 Chrome/Edge 로그인 프로필을 사용하지 않습니다. 사진 원본을 일괄 다운로드하거나 AI로 분석하지 않고 현재 브라우저에 로드된 이미지 URL·크기·제목을 기록합니다. 로고나 비관련 사진도 포함될 수 있어 사진 개수가 검색 성공을 증명하지는 않습니다. 원본 해상도/인물 일치/사용권은 별도로 확인해야 합니다.

Windows 실기 검증 전 도구입니다. Linux에서 ZIP·파서·보고서 로직을 검증했지만 Windows 브라우저 실제 동작은 아직 확인하지 못했습니다.
