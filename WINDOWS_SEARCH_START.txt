K-IDOL ARCHIVE — 1단계 Windows 브라우저 연결 실험판

이 파일은 기존 앱에 Kpopping 브라우저 검색 경로를 연결한 소스 실행판입니다.
정식 완료판/EXE가 아닙니다. Windows 실기와 다중 사이트 검색은 아직 검증하지 못했습니다.
Kpopping 하나로 지시서 전체를 완료한 것이 아닙니다.

1. 전체 ZIP을 새 폴더에 압축 해제합니다. 기존 사용자 데이터는 삭제하지 않습니다.
2. Python 3.12와 Microsoft Edge 또는 Google Chrome이 필요합니다.
3. START_WINDOWS.bat를 실행합니다. 첫 실행 때 기본/브라우저 Python 패키지를 설치합니다.
4. 앱의 [검색 출처]를 누릅니다. Kpopping과 Flickr 공개 태그 피드를 따로 선택할 수 있습니다. 출처별 공개 검색/미리보기 이용 조건을 직접 확인한 경우에만 근거를 기록하고 연결을 저장합니다. AI·원본 다운로드 권한은 허용되지 않습니다. 이전 Kpopping 연결 설정은 유지합니다.
5. 먼저 [장원영]을 입력하고 [인터넷 검색]을 누릅니다. 이 인물 목록 URL은 이전 사용자 Windows 보고서에서 확인한 실제 페이지입니다. 사진 속 인물 일치 보증은 아닙니다.
6. Kpopping은 Windows 브라우저를 열고 같은 인물 필터를 유지하며 스크롤을 처리합니다. Flickr는 브라우저나 API 키 없이 공개 태그 피드를 요청합니다. 선택한 두 출처의 요청을 병렬로 실행하고 먼저 받은 후보부터 기존 앱 갤러리에 연결합니다. 이 다중 출처 실동작은 아직 미검증입니다.
   [스크롤 시 더 검색]이 켜져 있으면 갤러리 하단에서 아래로 스크롤할 때 다음 배치를 요청합니다. 신규 후보가 없으면 자동 요청을 멈춥니다. [더 검색]으로 직접 다시 요청할 수 있습니다. 화면 갱신만으로 연속 요청하지 않습니다.
   검색은 기본 [검색 발견순]으로 표시해 새 결과가 뒤에 추가됩니다. 다른 정렬은 사용자가 선택할 수 있습니다.
7. 로드된 작은 이미지의 더블클릭은 기존 뷰어에서 [미리보기·원본 미확인]으로 표시합니다. 제공된 원본을 확인한 것이 아니므로 고화질 원본 확인 완료로 표시하지 않습니다.
8. 다른 인물/그룹은 검색 입력란과 정확한 선택지를 자동으로 찾으려고 시도합니다. 이 경로는 미검증이며 찾지 못하면 오류로 종료합니다. 아무 사진이나 대신 표시하지 않습니다.

실제 검색 시도 로그:
%LOCALAPPDATA%\K-IDOL-ARCHIVE\search-reports
실행 결과 JSON에는 검색어·후보 수·페이지·실패 원인만 기록합니다. 로그인 쿠키·헤더·브라우저 프로필은 저장하지 않습니다. 브라우저는 별도 세션으로 실행하며 로그인/CAPTCHA/robots 금지 시 중단합니다.

Flickr의 한계: 검색어를 태그 힌트로 전달하는 최근 공개 피드로 검색어별 최대 20개입니다. 검색어/별칭에 대응하는 태그가 없으면 결과가 없을 수 있습니다. 사이트 전체 검색·과거 페이지 탐색·원본 추출은 지원하지 않습니다. 태그는 사진 속 인물이나 구도가 맞다는 보증이 아닙니다.

미완료: 실제 다중 출처 사진 표시 검증, 그룹/솔로 자동 선택, 원본 확대/추출 확인, Google/Bing/X/Instagram/블로그 등 추가 출처별 접근·구조·이용 조건 검증. 스크롤 추가 요청 UI는 가상 응답으로 검증했으며 실사이트 전체 수집 확인은 아닙니다. 기존 일반 수집기·라이브러리·AI 기능은 보존했습니다. 이미지 분석 전에는 선택한 구도/색상 조건에 일치했다고 확정하지 않습니다.
