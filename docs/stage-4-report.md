# 4단계 · 멀티 소스 기반 · v0.4.0 Alpha 4

추가 지시서의 멀티 소스 확장 기반을 구현했습니다. 3단계의 실제 Wikimedia 연결 검증은 여전히 미완료입니다. 이 결과는 모든 출처의 자동 수집이나 AI 단계 완성을 의미하지 않습니다.

## 구현과 검증 범위

| 경로 | 현재 상태 |
| --- | --- |
| Wikidata / Wikimedia Commons | 기존 어댑터 유지. 실제 정책/API 검증은 프록시 403으로 미완료 |
| 검토된 공개 HTML / 직접 이미지 HTTPS URL | 일반 어댑터 구현, 합성 응답으로 검증 |
| JavaScript DOM | 선택 Playwright 어댑터 구현. 실제 Chromium 샌드박스로 합성 페이지 검증 |
| 공식 사이트 / X / Instagram / 언론 / 팬사이트 / Flickr / Kpopping | 출처 분류 및 비활성 검토 후보. 전용 연동 완료 아님 |
| 로컬 사진 | 기존 가져오기/참조/즐겨찾기 유지 |

기존 Provider를 확장하며 외부 플러그인은 도메인·속성·주기 등 JSON 데이터만 받습니다. 임의 Python/JavaScript 실행 플러그인을 설치하지 않습니다. 알 수 없는 링크는 인덱스만 등록합니다.

메타데이터 탐색, 썸네일, 원본 다운로드, 로컬 분석, AI 입력, 결과 저장을 소스/개별 사진별로 분리했습니다. DOM 실행도 별도 권한이 필요합니다. 검토 근거와 설정 해시를 기록하고 설정 변경 시 재검토합니다. Commons 파일 라이선스 자동 갱신은 사용자의 명시적 거부를 덮어쓰지 않습니다. 라이선스 메타데이터로 로컬 분석/AI 권한을 자동 부여하지 않습니다.

HTML src/srcset/picture/OpenGraph/JSON-LD 및 검토한 data 속성만 추출합니다. 고해상도 URL을 추측하지 않습니다. 원본 선언과 실제 검증은 구분하며 실제 픽셀·파일 크기·SHA256·디코딩 검사를 기록합니다. 게시일과 촬영일도 구분합니다. 개정본의 원본과 근거를 보존하며 자동 교체하지 않습니다. 썸네일 허용만으로 임의 원본을 받지 않습니다.

SHA256 동일 파일은 여러 출처 근거를 연결합니다. 별도 허용된 로컬 dHash 분석은 유사 후보만 제안하고 자동 병합/삭제하지 않습니다. 이름·별칭 언급도 실제 등장 인물 확정이 아닙니다. 사용자가 인물을 명시적으로 연결하며, 확인된 남성만 등장하는 원격 사진의 기본 숨김은 로컬 파일과 즐겨찾기를 삭제하지 않습니다.

## 성능과 자원

네트워크와 분석 작업을 별도 제한 큐로 나누고, 수동 작업은 선택 작업만 요청합니다. 자동 실행을 끈 상태에서 분석 요청이 무관한 네트워크 작업을 실행하지 않습니다. 페이지는 200건 단위로 표시하고 메인 갤러리는 출처별 필터와 선택 상태를 유지합니다.

일반 페이지 최대 2MiB/후보 300개, 원본 64MiB/4천만 픽셀, 썸네일 8MiB/4백만 픽셀로 제한합니다. DOM은 리소스 최대 20개/8MiB, 비동기 렌더 예산 18초와 정리 단계별 3초를 사용합니다. 네이티브 DNS/소켓/디코더 및 전체 프로세스 메모리의 절대 상한을 보장하지는 않습니다. 샌드박스를 유지하며 페이지의 직접 외부 네트워크, 이미지/미디어 다운로드, 로그인 세션과 서비스 워커를 차단합니다. 허용된 스크립트/스타일은 앱의 호스트·권한·robots 검사를 거칩니다. 스크린샷을 원본으로 저장하지 않습니다.

| 합성 메타데이터 | 첫 썸네일 | 마지막 페이지 | 이벤트 루프 최대 간격 | RSS 최고치 |
| --- | --- | --- | --- | --- |
| 1만 건 | 52.05ms | 5.50ms | 20.46ms | 121.18MiB |
| 10만 건 | 45.01ms | 13.34ms | 15.48ms | 143.43MiB |

메타데이터 상주 최대 2,048건. 실제 Qt offscreen 목록에서 생성 JPEG 하나를 별도 해시 레코드로 참조한 측정입니다. 고유 사진 10만 장 디코딩, 실제 화면 FPS 또는 Windows 실기 결과가 아닙니다. [원자료](virtual-gallery-profile-v0.4.json).

## 검증과 배포

Linux Python 3.12/PySide6 6.8.3에서 **91개 테스트 통과, 9.53초**, 실패/건너뜀 0. 실제 Chromium 154 샌드박스에서 외부 통신 없는 합성 DOM 테스트 2개 포함. [전체 결과](test-results-v0.4.xml). 마이그레이션 백업/롤백, 권한 분리/수동 거부, 메타데이터 전용 요청, URL/리다이렉트 범위, 버전/출처, 작업 분리, UI 출처 필터를 검증했습니다.

[화면](multisource-ui-v0.4.png)은 직접 생성한 도형과 가상 출처이며 실제 아티스트 또는 사이트 수집 성공 화면이 아닙니다. 선택 브라우저 의존성은 requirements-browser.lock에 고정했습니다. Windows 실행 파일은 생성/검증하지 않았고 소스 ZIP만 제공합니다. 브라우저와 드라이버는 소스 ZIP에 포함되지 않습니다.

DB v1/v2는 버전별 백업 후 스키마 v3로 원자적 이전합니다. 기존 인물/그룹/사진/즐겨찾기는 유지합니다. 업데이트 전 앱을 닫고 데이터 폴더를 별도 백업하세요. 이전 앱으로 새 DB를 열 수 없습니다.

## 남은 작업

현재 실행 환경은 네트워크 제한 적용 상태이며 사용자 추가 허용 도메인이 없습니다. 이전 Wikimedia 관련 7개 도메인 초안은 실행 환경에 반영되지 않았습니다. 환경 설정에서 검토·저장·게시 후 실제 정책/API 검증을 재개해야 합니다. 네트워크 허용은 이용 권한 확인과 별개입니다.

각 실제 사이트의 정책/API/robots와 개별 이미지 조건 확인, Windows 실행·배포 및 장기 수집 검증이 남아 있습니다. 원격·로컬 통합 사진 벽, 색상/구도/의미 분석, AI 모델/업스케일은 후속 작업입니다. 워터마크 제거·로그인/캡차 우회는 구현하지 않습니다.
