# 방향 수정 1단계 — 미완료 / Wikimedia 제외

사용자 추가 지시에 따라 **새 통합 검색에서는 Wikimedia를 제외했다.** 기존 보관 사진/원본/출처 정보는 삭제하지 않는다. 이 작업 중 추가했던 Commons 이름 검색 메서드와 인덱싱 변경도 철회했다. 기존 아티스트 메타데이터·보관 기능은 보존한다.

## 실제 변경

- 검색 세션/결과 연결 테이블을 트랜잭션으로 추가했다. 기존 schema7의 자산·즐겨찾기·AI 결과를 수정하지 않는다.
- 기존 LibraryRepository가 검색 세션 범위를 지원한다. 결과는 기존 web 이미지 ID를 사용하고 저장된 경우 linked_asset_id로 이어진다. 새 사진 저장소나 별도 뷰어를 만들지 않는다.
- 기존 검색창에 인터넷 검색/Enter·구도·미확정 포함·다음 검색 버튼을 연결했다. 기존 로컬 검색/뷰어/필터/AI는 유지한다. 검색 중심 홈 전환은 아직 하지 않는다.
- 확인돼 저장된 이름/별칭과 구도 관련 키워드를 최대 8개로 확장한다. 키워드는 발견 힌트이며 인물 등장이나 구도 조건 일치를 자동 확정하지 않는다.
- 일반 검색 Provider 경계를 만들고, 검토된 HTML 검색 URL 템플릿을 기존 WebService/robots/출처 권한 검사/이미지 파서에 연결했다. 설정은 image_search_templates의 source/template이다. 템플릿은 승인된 출처 도메인만 사용하고 인코딩된 {query}를 넣는다.
- **현재 실제 검증해 기본 활성화한 출처는 없다.** Google/Bing/Kpopping/X/Instagram/Flickr/블로그가 동작한다고 표시하지 않는다. 설정을 적는 것만으로 해당 사이트가 지원되는 것은 아니다.
- 일반 페이지 템플릿 어댑터는 첫 페이지 경로만 연결했다. 사이트별 결과 구조·원본/썸네일 구분·다음 페이지 탐색은 실제 출처 응답과 정책 확인 후 구현해야 한다. 현재 공통 파서는 검색 페이지의 로고나 비관련 이미지를 구별하는 사이트별 로직을 대신하지 않는다.
- 세션 ID로 이전 요청의 늦은 응답을 현재 화면과 분리하고 반복 커서를 차단한다. 한 제공처가 실패하면 다음 검색 계획을 남기며 자동 무한 재시도하지 않는다.

## 실제 외부 검사

과거 Commons 검색은 프록시 403이었고 이제 검색 대상에서 제외했다. 새 조사 대상 Kpopping의 robots.txt도 **HTTP 403**으로 차단됐다. 최신 이용 조건/자동 접근 허용을 확인한 것이 아니며 실제 이미지 수집·갤러리·원본 뷰어를 성공시킨 기록도 없다. `docs/live-checks/search-stage1.json`에 과거/현재 증거를 구분했다.

현재 관리 환경은 제한 정책이 enforced이며 적용된 custom allowed_hosts는 비어 있다. 환경 초안의 네트워크 목적지를 Google/Bing/Kpopping/Flickr/X/Instagram/Naver Blog/Tistory 조사용 8개 호스트로 변경하고 재개 안내를 저장했다. **이 목록은 지원 출처 목록이 아니다. 저장은 적용/게시가 아니다.** 기존 Wikimedia 전용 도메인 초안은 제거했다. 프록시/CAPTCHA/인증/TLS 제한을 우회하지 않는다.

환경 설정에서 초안을 검토·저장·게시한 뒤 적용 상태와 실제 접근을 재검사해야 한다. 그 이후 공식 이용 조건/robots와 실제 검색 응답을 확인한 출처부터 연결한다. 유료 API나 계정 인증은 임의로 진행하지 않는다. 일반 브라우저에 보이는 이미지 주소만으로 분석/저장/AI 사용을 자동 허용하지 않는다.

## 검증 범위

새 검색 테스트는 명시적인 **가상 출처 응답**으로 기존 웹 갤러리 연결, 페이지/중복/세션 격리, 템플릿 도메인/권한 검증, Wikimedia 자동 대체 금지, 한 제공처 실패 시 다른 검색 유지와 Qt UI 연결을 확인한다. 실제 인터넷 검색 성공 증거가 아니다. 전체 회귀는 186개 통과, 36.63초이며 기존 protobuf 경고 2개가 있다. 마지막 설정 오류 격리 보강 후 검색 전용 7개도 재검증했다. 실제 sandboxed Chromium fixture 2개를 포함한 전체 결과는 docs/test-results-search-stage1.xml에 기록했다.

## 다음 진행

1. 저장한 환경 네트워크 초안을 적용한 후 비파괴적 실제 접근/정책 조사를 수행한다.
2. 실제 이용 가능한 비-Wikimedia 출처의 검색 응답을 기존 갤러리에 연결해 인물/그룹/솔로, 썸네일, 추가 페이지와 기존 뷰어를 검증한다.
3. 실제 외부 사진 흐름이 통과한 뒤에만 2단계 검색 중심 UI와 3단계 자동 갱신/배포로 진행한다.

무한 스크롤, 다중 사이트 실동작, 검색 조건 변경에 따른 추가 수집, 온라인 썸네일 분석/일치 우선 정렬, 관심 아티스트 검색 갱신은 미완료다. Windows 실행본을 만들지 않았고 기존 v0.7.4 ZIP도 이번 변경을 포함하지 않는다. 이 단계는 완료가 아니다.
