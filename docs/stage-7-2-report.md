# 7-2 · 색상 탐색과 로컬 구도 분석 · v0.7.2

## 구현

상단 **필터 · 이미지 분석**에서 HEX, Lab ΔE76 허용치, 최소/최대 점유율, 영역, 구도, 검출 인원, 실측 해상도와 비율을 조합한다. 색상 점유율 내림차순 정렬과 미분석/미확정 포함을 지원한다. 필터를 적용한 목록과 뷰어의 탐색 범위를 공유한다. 모델리스 창이므로 갤러리와 함께 사용할 수 있다.

전체 이미지 색상 분석은 기본 설치에서 동작한다. 긴 변 128px 표본의 최대 64색 팔레트로 근사하며, 투명 픽셀은 제외하고 반투명도는 가중한다. D65 CIE Lab 공간에서 RTree 후보 검색 후 정확한 ΔE76 거리 범위를 적용한다. RTree 미지원 SQLite에서는 일반 테이블로 대체한다. 점유율 0%는 분석 미완료와 구분하며 미분석 포함은 별도 선택이다. 실제 픽셀 전수 측정이나 ΔE2000은 아니다.

선택 설치 MediaPipe 0.10.21의 동봉된 CPU 모델로 얼굴·포즈와 인물/배경 마스크를 계산한다. 추가 모델 다운로드는 하지 않는다. 네 모델의 SHA256을 실행 전 확인한다. 전신은 머리부터 발까지 필요한 관절이 실제로 검출된 경우에만 후보로 제안한다. 극근접/근접/어깨/상체/허리/무릎 후보와 얼굴 검출 수 기반 1명/2명/그룹 후보를 제공한다. 검출 부족은 미확정이며 옆모습/뒷모습은 수동 확인 대상이다. 사람의 신원·성별을 추정하거나 얼굴로 인물을 연결하지 않는다.

영역은 주 인물/배경/포즈 기반 상체 ROI이다. 상체 ROI는 옷만 분할한 영역이 아니며 머리카락 전용 분할은 없다. 연관 사진은 배경/상체 색상이 가까우면서 확인된 같은 인물 또는 기록된 같은 촬영일 조건을 만족하는 후보만 추가한다. 색상 유사성으로 같은 의상·장소·촬영을 확정하지 않는다. 실제 인물 사진의 정확도 평가 자료가 없으므로 구도와 영역 기능은 실험적 후보로 제공한다.

## 성능·권한·데이터

분석은 저우선순위 로컬 작업 1개로 제한하고 CPU 그래프 내부 스레드도 1개로 설정한다. 검색과 디코딩은 UI 스레드에서 실행하지 않는다. 취소 시 SQL progress handler가 조회를 중단한다. 분석 입력은 최대 40MP, 추론 긴 변 768px로 제한한다. 취소가 네이티브 디코더 호출을 즉시 중단하거나 전체 프로세스 메모리 상한을 보장하지는 않는다.

SHA256·파일 서명·분석기 버전이 같은 결과는 재사용한다. 같은 바이트의 재연결도 현재 권한을 확인한 결과를 재사용한다. 파일이 변경되면 분석 시 해시 불일치로 차단한다. 외부 파일의 지속 감시 기능은 없으며 검색은 마지막 등록·검증 상태 기준이다. 변경된 파일은 재등록이 필요하다.

등록 파일 또는 이미 검증된 보기 캐시만 입력으로 사용한다. 분석 요청이 원본을 다운로드하지 않는다. 로컬 사진은 출처와 사진별 분석 허용이 모두 필요하며 원격 항목은 해당 출처·항목 권한을 확인한다. 픽셀 접근 전과 결과 게시 직전에 재검사하며 철회된 결과는 검색에서 제외한다. 분석 허용은 AI 복원 입력 허용과 별개이다. 자동 분석은 기본 꺼짐이며 켠 경우만 허용된 캐시/사진을 제한된 배치로 처리한다. 실패·차단된 동일 요청은 자동 무한 재시도하지 않는다.

수동 구도·인원 확인은 자동 분석보다 우선한다. 수정은 사진 해시에 묶고 이력을 보존한다. 스키마 6→7 마이그레이션 전 백업하며 오류 시 분석 테이블/RTree 생성도 트랜잭션으로 되돌린다. 모델 작업 메모리를 해제하는 기능을 제공하지만 이미 로드한 Python 모듈까지 내려 전체 RSS를 초기화하지는 않는다.

## 검증 결과와 한계

Linux Python 3.12.14에서 **156 passed**, 21.79초. 실제 샌드박스 Chromium fixture 테스트 2개를 포함한다. 새 분석 테스트 16개는 Lab 기준값, 투명도, 점유율 범위와 0%/미확정, 권한 철회, 해시 변경, 같은 바이트 재사용, 취소, 수동 수정 이력, 마이그레이션 백업/롤백, 모델리스 UI와 실제 오프라인 CPU 모델 실행을 확인한다. protobuf의 Python 3.14 관련 deprecation 경고 2개가 있으며 현재 검증 버전은 3.12이다.

실제 모델 검증 입력은 직접 생성한 단색 이미지이다. 모델이 실행되고 미확정으로 반환하는지 확인했으며 실제 인물의 구도 정확도나 의상/배경 의미 인식 성능을 입증하지 않는다. 화면 자료도 직접 생성한 색상 도형 사진이다.

[측정 원문](color-search-profile-v0.7.2.json): 사진당 미리 계산한 합성 색상 4개, 현재 사진별 권한 확인, 결과 수 계산 및 점유율 정렬 첫 256건 포함.

| 합성 사진 수 | 색상 행 | 첫 조회+개수 | 프로세스 최대 RSS |
|---|---:|---:|---:|
| 10,000 | 40,000 | 52.68ms | 48.15MiB |
| 100,000 | 400,000 | 502.70ms | 56.45MiB |

이는 SQL 벤치마크이며 디코딩/모델 메모리/화면 FPS 측정이 아니다. 실제 사진은 영역별 최대 64색으로 색상 행이 더 많을 수 있다. 10만 장에서 즉시 결과를 보장하지 않으며 향후 실제 라이브러리 측정이 필요하다.

## 실행과 남은 작업

기본 의존성만으로 전체 색상 분석/필터/수동 확인을 사용할 수 있다. 선택 모델은 소스 환경에서 `python -m pip install -r requirements-analysis.lock`로 설치한다. Linux에서 설치·실행 검증했으며 Windows 선택 모델 호환성은 검증하지 않았다. 기본 Windows 빌드 스크립트는 선택 CV 패키지를 제외한다. Windows EXE 자체도 아직 빌드/실행 검증하지 않았다.

선택 모델 해시 및 라이선스 근거는 [모델 명세](analysis-model-manifest.json), 배포 고지는 analysis-dependencies 폴더에 있다. 소스 ZIP에는 모델 가중치나 .venv를 포함하지 않는다. MediaPipe 태그의 공식 Apache LICENSE도 확인·보관했다.

7-1의 실제 Wikimedia 연결은 기존 프록시 403 상태로 미검증이며 이번 기능과 분리되어 있다. 7-3의 실제 AI 업스케일·참고 사진 복원, 7-4의 Windows/실사용 최종 검증은 남아 있다. 이번 단계에서 AI 복원을 구현했다고 주장하지 않는다.
