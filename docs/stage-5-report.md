# 5단계 기반 · 연관 사진·인물 참조 후보 · v0.5.0 Alpha 5

추가 지시서에 따라 연관 사진 검색과 출처 권한을 적용한 참조 후보 탐색을 구현했습니다. **5단계의 기반 납품이며, AI 인물 참조 복원까지 완료한 Beta 3는 아닙니다.** 앞 단계의 실제 사이트 연결과 정책 검증도 계속 미완료입니다.

## 실제 구현 범위

| 기능 | 동작과 한계 |
| --- | --- |
| 연관 사진 검색 | 로컬 등록/보관 사진에서 확인 인물·그룹·촬영일·게시일·출처 페이지를 비교. 근거와 규칙 점수 표시 |
| 시각적 유사 후보 | 기존에 허용되어 계산된 dHash를 현재 파일 버전과 양쪽 분석 권한 확인 후 연결. 정체성/행사 판정 아님 |
| 동일 행사 확인 | 사용자가 근거를 기록한 양방향 관계. 자동으로 같은 행사라고 확정하지 않음 |
| 수동 연결/제외/해제 | 사진·인물 관계·원본을 유지하고 관계 기록만 변경. 재검색 시 제외 유지 |
| 뷰어 필름스트립 | 기본 숨김, 최대 12장, 한 작업 스레드에서 순차 썸네일 표시. 전체화면 조작부와 숨김/복원 |
| 인물 참조 후보 | 확인된 Person ID 선택, 기준/후보별 분석·AI 입력 권한 적용. 전체 픽셀 수를 보조 정렬에 사용 |
| 로컬 권한 기록 | 검토 근거를 입력한 선택 사진만 개별 허용/거부. 한 사진의 거부가 다른 사진의 권한을 취소하지 않음 |
| 근거 보존 | 검색 규칙 버전, 기준/후보 해시, 점수/이유 및 수동 확인 근거 기록 |

실제 등장 인물은 사용자 확인 연결만 사용합니다. 이름 언급이나 그룹 연결은 얼굴 확인이 아닙니다. 촬영일과 게시일을 별도 근거로 표시하고 등록일로 대체하지 않습니다. 같은 날짜/출처/인물만으로 같은 촬영이라고 확정하지 않습니다. 서로 다른 사진을 유사도에 따라 삭제·병합하지 않습니다.

원격 사진은 파일 버전과 개별 권한을 확인합니다. 같은 파일에 로컬 등록 표시가 추가되어도 원격 출처 조건을 우회하지 못합니다. 과거 보관 개정본에 현재 URL의 새 개정본 권한을 적용하지 않습니다. 현재 개정본과 일치하지 않는 과거 파일은 보수적으로 표시/참조 후보에서 제외합니다. 표시·원본 보기·분석·AI 입력·결과 저장은 독립 권한입니다. 이번 기능은 AI 모델 입력이나 결과 파일을 생성하지 않습니다.

권한은 검색 및 썸네일 작업/뷰어 진입 시 재확인합니다. 검색 근거 기록은 허가 토큰이나 재사용 결과 캐시가 아닙니다. 외부 참조 파일의 전체 해시를 매 검색 때 다시 읽지는 않습니다. 향후 실제 모델 입력 전에는 파일 무결성과 권한을 다시 검증해야 합니다.

## 성능과 데이터 보호

검색·원본 목록 준비·수동 관계와 권한 저장은 작업 스레드에서 처리합니다. 저장 중 닫기를 요청하면 기록 완료 후 종료하며, 실패 시 창에 오류를 알립니다. 세대 번호/취소 상태로 오래된 결과를 무시합니다. 필름스트립은 기본 감상 중 실행되지 않으며, 펼치면 최대 12개 항목을 만들고 한 장씩 순서대로 썸네일을 갱신합니다. 숨기기/종료 시 작업을 취소하고 표시 자원을 정리합니다. 네이티브 디코더 내부 작업은 즉시 중단할 수 없습니다.

후보는 근거별 최대 256건, 보유 후보 최대 1,024건, 결과 최대 120건입니다. 인물/그룹/출처 분기와 수동 관계에도 상한을 두며 제한이 감지되면 UI에 표시합니다. 전체 라이브러리의 모든 유사 사진 또는 최적 참조를 반환하는 완전 검색은 아닙니다. 날짜와 관계의 역방향 인덱스를 추가했습니다. 사진 픽셀 분석을 새로 수행하지 않고 기존 특징을 활용합니다.

| 합성 메타데이터 | 연관 후보 검색 | 반환 결과 | 검색 프로세스 RSS 최고치 |
| --- | --- | --- | --- |
| 1만 건 | 77.25ms | 120건 | 17.88MiB |
| 10만 건 | 81.38ms | 120건 | 18.77MiB |

[연관 검색 원자료](related-profile-v0.5.json). SQLite 작업과 생성 메타데이터만 측정했으며 실제 사진의 관련성 정확도나 디코딩 시간 측정이 아닙니다.

기존 실제 Qt 가상 목록의 10만 건 마지막 페이지 이동 **13.16ms**, 첫 썸네일 **48.10ms**, 이벤트 루프 최대 간격 **14.29ms**, RSS 최고치 **146.24MiB**. 메타데이터 상주 최대 2,048건. [원자료](virtual-gallery-profile-v0.5.json). 한 생성 이미지를 여러 해시 레코드로 참조한 Linux offscreen 측정이며, 고유 사진 10만 장이나 Windows 화면 FPS 결과가 아닙니다. 단일 측정이므로 장치별 성능 보증으로 해석하지 않습니다.

DB 스키마 v4로 원자적 이전하며 기존 v1/v2/v3는 SQLite backup API로 고유 백업을 남깁니다. 사진·그룹·인물·즐겨찾기와 기존 출처/권한을 유지합니다. 관계 해제는 관계 기록만 지웁니다. 업데이트 전 앱을 닫고 전체 데이터 폴더를 별도 백업하세요. 이전 버전으로 새 DB를 열 수 없습니다.

## 검증과 산출물

Linux Python 3.12 / PySide6 6.8.3에서 **103개 테스트 통과, 10.76초**, 실패/건너뜀 0. 실제 Chromium 샌드박스를 유지한 외부 통신 없는 DOM fixture 테스트 2개 포함. [전체 결과](test-results-v0.5.xml).

신규 회귀 테스트는 근거 분리, 게시일/등록일 오판 방지, 양방향 제외와 해제, 명시적 Person ID, 사진별 권한 거부, 원격 출처를 로컬로 우회하지 못함, 개정본 변경, 현재 유사 특징/권한 재검사, 후보 상한과 취소, 비동기 UI/뷰어, 필름스트립 상한과 늦은 응답, 저장 완료 후 닫기, v3 백업 및 DDL 전체 롤백을 확인합니다.

화면은 직접 생성한 도형과 가상 인물의 합성 데이터입니다. 실제 아티스트/사이트/AI 복원 성과를 보여주는 화면이 아닙니다. 새 의존성이나 모델 가중치를 추가하지 않았습니다. 기본/선택 브라우저 의존성은 이전 버전의 잠금을 유지합니다. 소스 ZIP과 SHA256을 제공하며 Windows 실행 ZIP은 아직 생성/검증하지 않았습니다.

## 남은 범위와 연결 상태

이번 단계에 새 실제 사이트 Provider를 활성화하지 않았습니다. Commons와 일반 HTML/DOM 어댑터는 기존 상태를 유지하며 X·Instagram·Flickr·Kpopping·언론/공식/팬 사이트는 여전히 검토 후보입니다. 실행 환경의 사용자 추가 허용 도메인이 없어 이전 Wikimedia 7개 도메인 초안도 아직 적용되지 않았습니다. 환경 설정에서 검토·저장·게시 후 실제 정책/API/권한/파일 검증을 진행해야 합니다.

5단계 전체 완료에는 의상·배경·얼굴 방향/크기·선명도와 의미 기반 연관성 평가, 검증된 모델의 참조 복원, 입력/결과 사용권 확인, 정체성 보존 실험, 원본·일반 업스케일·참조 복원의 3중 비교가 남아 있습니다. 현재 전체 픽셀 수나 확인된 인물 링크는 복원 적합성/동일인 진위를 보증하지 않습니다. 저장 전 원격 후보를 포함하는 통합 사진 벽, 추가 실제 소스, 장기 운영 및 Windows 실기/배포 검증도 후속 작업입니다.
