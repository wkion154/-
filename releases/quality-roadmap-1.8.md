# 완성도 개선 3단계 · 사용자 의견 통합

점수는 주관적 목표이며 기능 수나 테스트 통과로 80~90점을 확정하지 않습니다. 콘텐츠 종류 증가를 멈추고 조작 신뢰성 → 주민 애착 → 장기 재미 순서로 보완합니다.

1. **화면·조작·설명** — 1.8. 첫 정착 실습과 목표, 실제 비용·결과·대기 이유, 공통 버튼 규격, 개척단 잠금 시 배치 유지, 검은 바닥 수정, 작은 말풍선/전문, 확대 이름표, 카드형 알림/펼침 유지, 우클릭 취소/바깥 클릭/고정 닫기, 목적별 색, 소수점 정리, 메뉴 중복 제거, 전방 위치/처치 연출. 저장 보존과 실제 와이드 화면 조작으로 확인합니다.
2. **주민의 개성과 관계** — 성격에 맞는 자연스러운 말투·상대 응답·침묵·반복 제한. 기억→관계→행동의 연결. 눈/눈썹/입·머리/수염·메이크업·흉터·의상 등 실제 화면에 드러나는 외형 확대. 성별과 연애 선호를 구분하고 성인 주민의 애정·거절·질투·이별·화해 및 개인의 편견 갈등을 관계/기억 시스템에 연결. 기존 주민의 외형·관계를 임의로 덮어쓰지 않습니다.
3. **변화하는 세계와 장기 목표** — 기존 지역의 재방문 이유·선택의 후속 결과, 짧은 연속 사건, 현재 마을과 주민에 맞는 의뢰/보상, 방치형 방어 준비와 복구, 자원 누적·유일한 정답 편성·회복 불능 연속 위기 보완. 첫 30분/2~3시간/10시간 이상/자동 운영/Windows 실기 검증으로 실제 재미와 안정성을 평가합니다.

각 단계에서 플레이 가능한 배포본을 만들고 발견된 문제를 다음 단계보다 먼저 수정합니다. UI만 고친 결과를 성별/연애나 장기 세계 변화까지 구현했다고 표현하지 않습니다. 사용자 의견의 '시스템끼리 자연스럽게 연결'은 모든 단계의 공통 기준입니다.
