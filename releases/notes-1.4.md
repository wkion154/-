# 1.4.0 — 후속 1단계: 읽기 쉽고 부드러운 화면

장기 정착지 게임으로 발전시키기 위한 후속 세 단계 중 첫 단계입니다. 이번에는 관찰·조작·설명을 개선합니다. 분야별 능력·랜덤 시작 지형·장기 노화와 위기 구조·대규모 원정/방문/퀘스트·자동 방어는 다음 단계의 범위이며, 현재 분량이 수백 시간으로 완성됐다는 뜻은 아닙니다.

## 이동과 지도

- 현실 1초마다 여러 게임 초를 몰아서 실행하던 방식에서, 배속에 맞춰 고정 게임 초를 순서대로 실행합니다. 화면은 실제 이동 구간의 경유점을 이어 그려 8배에서도 중간 길을 건너뛰지 않습니다.
- 같은 게임 초와 명령에서는 1/2/4/8배의 자원·난수·실제 위치 결과가 같습니다. 표시용 경로와 카메라는 저장 규칙을 바꾸지 않습니다.
- 동작 줄이기에서는 장식 흔들림을 줄이고 위치 이동은 연속 표시합니다. 큰 응답 지연(2초 초과)에서는 일시정지하고 알립니다. 타이틀·선택 대기·모달·숨겨진 탭에서는 시뮬레이션이 진행하지 않습니다.
- 지도 크게 보기/작게 보기, 휠 포인터 중심 확대·축소, 좌클릭 드래그, 전체 보기 복귀, 선택한 주민의 실제 경로 표시를 추가합니다. 크게 보기 안에서도 선택 주민의 몸·마음·현재 행동과 상세 정보를 확인합니다.
- 건설 중 클릭은 위치 지정입니다. 지도 이동은 가운데 버튼 또는 지도 위 Space+드래그를 사용하세요. 확대 후에도 주민·시설·건설 판정은 실제 보이는 좌표와 같습니다.
- 중요한 선택의 배경 확인에서도 확대·이동·조회는 가능하고 시간·건설·출정·사회 행동은 잠깁니다.

## 읽기와 설명

- 고정 헤더에 게임 속 날짜·시각·배속·정지 이유를 묶었습니다. 하루 60게임 초를 유지하며 표시 시각은 1게임 초마다 24분씩 흐릅니다. 낮밤 표현의 시작점과 맞췄습니다.
- 위기 이름·남은 시간·대응 게이지·관련 버튼을 가까이 묶고 안내의 과도한 좌우 분산을 줄였습니다.
- 자원·생활 역할·건설·장비·상태·성향·주요 버튼에 툴팁을 넣었습니다. 키보드 포커스로도 읽으며 비활성 작업은 설명 영역에서 사유를 봅니다. 관련 자원과 대상은 같은 강조색으로 연결됩니다.
- 성격은 현재 실제 효과를 설명합니다. 호기심·끈기의 학습 효과와 출신별 생활 이점, 말투에 반영되는 성향을 구분합니다.
- 체력·스트레스에는 철수 위험선을 표시합니다. 출정 가능 조건과 자동 철수 조건은 다르며, 장기전도 자동 철수 사유임을 알립니다. 회고에는 당시 대원의 상태 또는 장기전 이유가 남습니다.
- 처음 하는 법은 여섯 장의 그림 흐름·실제 주민 얼굴·공통 아이콘을 중심으로 구성하고 긴 설명을 접었습니다. 설정에서 다시 볼 수 있습니다.

## 선택과 대화

- 전체 확장·시설 개선·제작·원정 출발·위기 물자 투입·시설 철거·예약 취소·수동 귀환·은퇴·진행 중 개인 목표 변경을 실행 전 확인합니다. 실제 비용·전후 잔액·효과·잔류 인원을 표시합니다.
- 확인 중에는 시간이 멈추며 취소는 자원·난수를 바꾸지 않습니다. 확정은 한 번 처리하고, 상태가 바뀌었다면 내용을 다시 확인합니다. 기존 배치 미리 보기와 사건의 명시적 선택은 그대로 사용합니다.
- 말풍선은 전체 대사를 줄바꿈하고 가장자리에서 위치를 보정합니다. 배속과 별개의 현실 읽기 시간을 사용하며, 호버·정지·모달 중에는 표시를 유지합니다. 대사 기록과 실제 사회 효과 시간은 별개입니다.
- 대화 목록은 모든 발언에 해당 주민의 커스터마이징된 얼굴·이름을 붙입니다. 전후 수치 변화는 대사 아래에 모읍니다.
- 불 곁의 기록의 공간 채움·최대 100개 표시·스크롤과 긴 문장 처리를 유지합니다.

## 업데이트와 검증

게임에서 저장한 뒤 브라우저 탭과 검은 실행 창을 닫고, 새 ZIP 전체를 새 폴더에 풀어 Start.cmd를 실행합니다. 같은 PC·브라우저·주소에서 타이틀의 이어하기를 선택합니다. 업데이트 전 저장 내보내기로 별도 보관할 수 있습니다.

저장 형식은 기존 9를 유지합니다. 기존 주민 수·외형·나이·관계·시설·길·공사·원정·기억을 보존합니다. 새로운 네 명의 야영지는 새 게임에서 선택하고, 확정하기 전까지 기존 저장이 유지됩니다.

규칙 검증과 실제 Chromium 조작으로 확인합니다. 배속별 결과 동등성, 모서리 경로, 카메라 좌표와 드래그 오클릭 방지, 확인 취소·실제 비용, 툴팁·그림 안내·대사 전문·화자 얼굴·선택 대기 잠금, 기존 플레이·타이틀·공사·대화 저장을 검사합니다. 8배 실제 화면에서는 프레임별 인물 좌표를 수집해 급격한 건너뛰기가 없는지도 검사합니다.

Windows 실기 실행은 미검증입니다. 공식 Windows 런타임 SHA256·ZIP CRC·내부 파일 체크섬과 압축 해제본을 검증합니다. 장기 재미와 수백 시간 콘텐츠 검증은 이 화면 업데이트의 테스트 결과와 구분합니다.
