# 1.2.0 — 네 명의 개척단과 직접 짓는 마을

약속한 2단계 업데이트입니다. 성격·기억·상황에 맞춘 대화와 후속 사회 행동 확대는 3단계입니다.

- 새 게임에서 네 슬롯의 주민을 직접 뽑습니다. 개별/전체 재굴림, 잠금, 미확정 구성 저장 복원을 지원합니다. 주사위는 게임 진행 난수와 분리되어 있습니다.
- 이름·머리·피부·옷·얼굴 특징·장신구를 고르면 초상화·지도·전투에 같은 모습이 적용됩니다. 플레이 중에도 「꾸미기」로 이름·외형만 바꿀 수 있습니다. 출신은 해당 생활 작업에 +15%의 작은 이점을 줍니다.
- 새 마을에는 텐트 두 동·테이블·모닥불·보급 상자만 있습니다. 시설 없이도 채집·자재 수집·기초 응급처치·야영 휴식이 가능합니다.
- 「마을 → 건설·길」에서 시설을 고르고 지도에서 위치·방향·입구를 확인한 뒤 예약합니다. 거점에 있는 건설 담당자가 걸어가 작업합니다. 최대 세 건의 순서 변경·미사용 재료 반환 취소를 지원합니다.
- 흙길·포장길·길 철거는 시작과 끝을 정해 예약합니다. 실제 이동 속도는 흙길 +30%, 포장길 +65%이며 경로도 길의 이동 비용을 반영합니다. 길로 마을 전체 생산량을 중복 배율 증가시키지는 않습니다.
- 완성된 시설은 지도에서 선택해 작업으로 이설·철거할 수 있습니다. 숙소 철거로 현재 주민의 잠자리가 부족해지면 막습니다.
- 새 야영지의 장비 제작은 건설 담당자의 작업으로 완성됩니다. 방패·응급 가방은 야영 설비에서, 나머지는 작업장 건설 후 만들며 완성 뒤 착용합니다.
- 두 명 또는 세 명이 원정을 갑니다. 2인은 식량 6·구급약 최대 2개, 3인은 식량 8·구급약 최대 3개를 챙깁니다. 잔류 인원과 생활 역할을 출정 전에 함께 표시합니다.
- 균형·건설·회복 운영 방침과 자동 보조·회복 후 복귀를 지원합니다. 개별 역할을 직접 정하면 그 지시를 우선합니다. 운영 방침을 바꾸면 자율 보조를 다시 적용합니다.
- 계승자는 나이·경험·외형을 유지한 채 잠기고, 동료 세 명을 새로 고릅니다. 기록만 계승한다면 네 명 모두 뽑을 수 있습니다.

## 업데이트와 기존 저장

게임에서 저장하고 탭과 검은 실행 창을 닫은 뒤 새 ZIP 전체를 풀어 Start.cmd를 실행합니다. 같은 브라우저·주소에서는 이전 저장이 이어집니다. 기존 여섯 주민과 시설·장비·원정은 유지합니다. 기존 마을의 기본 자원 생산은 호환 방식으로 보존하고, 새 공사와 길의 이동은 적용합니다. 새 야영지부터 생활 작업의 실제 이동·도착을 생산에 반영합니다.

새로운 네 명의 야영지를 시작하려면 이전 진행을 「설정 → 저장 내보내기」로 보관한 뒤 「새 여정」을 사용하세요. 네 명을 확정하기 전 취소하면 기존 마을로 돌아갑니다. 새로 확정하면 현재 저장이 새 게임으로 바뀝니다.

저장 형식은 8입니다. 외형, 시설 위치·방향, 길, 예약 재료·공사 진행도와 이동 경로를 저장합니다. 이전 저장은 추가 정보만 변환하며 주민을 삭제하지 않습니다.

Windows 10/11 x64와 최신 Edge/Chrome용입니다. Node 런타임을 포함해 설치·인터넷·API 키 없이 실행합니다. Linux에서 엔진·실제 브라우저·배포 ZIP을 검증하며, Windows 실기 실행 여부는 별도입니다.
