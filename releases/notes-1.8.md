# 1.8 · 조작·가독성 개선 1단계

이전 첫 플레이 안내·비용/대기 이유 표시 작업에 사용자의 UI 의견을 합쳤습니다. 종류를 추가하는 업데이트가 아니라, 기존 콘텐츠를 이해하고 조작하는 경험을 다듬는 첫 단계입니다. 주민 외형 확대·성별/연애/질투·대화의 큰 개편은 2단계, 장기 지역 변화와 경제는 3단계에 남깁니다. 이 버전만으로 주관적 완성도가 80~90점에 도달했다고 평가하지 않습니다.

## 시작과 목표

- 새 야영지의 실습은 첫 시설 완공 → 두 주민의 직접 분업 → 2/3인 출정 → 원정 길/사건 선택 → 귀환 → 회복의 여섯 항목입니다. 첫 원정 완주를 요구하지 않습니다. 실제 행동으로 완료되며 기록은 저장됩니다. 정한 역할은 추천 배치로도 연습할 수 있습니다.
- 현재 목표 하나와 다음 목표 하나를 표시합니다. 첫 건설의 관련 그림 안내는 건설 화면과 해당 설명으로, 이후 항목은 관련 튜토리얼 페이지로 이동합니다. 일반 전체 튜토리얼 버튼은 처음부터 볼 때 사용합니다.
- 첫 안내와 기록 → 여정의 목표에서 첫 정착, 계절 대응, 성소 완주, 정착 계속/선택적 계승을 구분합니다. 현재 대응 점수와 완료 여부를 확인합니다.
- 진행 중인 건설/연구/사업에 담당자 없음·회복/교류 중·현장 이동·방어 참여·통로 문제·앞선 작업 대기 등의 사유를 표시하고 담당 주민으로 이동할 수 있습니다.
- 주민 상세에 현재 휴식·교류·이동·자동 보조의 이유를 표시합니다. 채집·자재 수집·휴식 스트레스 회복에 적용되는 공통 여건은 게임과 화면이 같은 계산 함수를 사용합니다. 건설 속도나 치료량 전체를 뜻하는 수치로 표시하지 않습니다.

## 화면과 조작

- 검은 바닥의 원인은 시작 조건 9종에 비해 바닥색 배열이 3종만 남은 것이었습니다. 아홉 조건의 색을 지정하고 안전한 기본색을 둡니다. 기존 지형 시드와 타일은 바꾸지 않습니다.
- 말풍선은 화면 기준 폭 약 180px, 본문 11px, 한 번에 세 줄로 줄입니다. 긴 문장은 여러 페이지로 보여 주며 페이지 수와 전문 보기 표시가 나옵니다. 긴 말풍선을 눌러 얼굴·이름과 전체 대사를 읽거나 대화 기록으로 이동합니다. 화면 크기 제한 때문에 폭은 약간 달라질 수 있습니다.
- 이름표는 기본 화면에서도 읽을 수 있는 크기를 확보하고 지도 확대에 따라 최대 1.45배 커집니다. 지도에는 현재 생활 역할의 작은 표식도 붙습니다.
- 아이콘/텍스트 버튼, 도움말 카드, 첫 사용 안내의 이전/다음, 개척단 잠금/주사위 버튼의 높이를 통일합니다. 비활성 버튼을 툴팁용으로 감싸도 크기가 바뀌지 않습니다. 잠금과 잠금 해제 때 개척단 편집 영역이 밀리지 않습니다.
- 상단은 계절 위기·침입/의뢰·최근 결과 카드로 나눕니다. 목적별로 절제된 회색 녹색·푸른 회색·황토/연두 계열을 쓰고, 제목과 행동의 위치를 맞춥니다. 결과를 펼치면 카드 아래에 상세가 열려 옆 카드가 빈 긴 상자가 되지 않습니다. 좁은 화면은 일반 흐름으로 펼칩니다.
- 결과·능력·도감 등 펼침 상태를 실시간 갱신에서도 유지합니다. 검색어·목록 스크롤과 입력 위치도 가능한 범위에서 보존합니다.
- 설치/길 배치 중 지도에서 우클릭하면 현재 청사진만 취소합니다. 이미 예약한 작업은 대기열의 취소로 처리하고 미사용 비용만 환불합니다. 우클릭으로 예약된 건물을 철거하거나 환불하지 않습니다.
- 일반 창에는 스크롤 중에도 남는 우측 상단 닫기 버튼을 둡니다. 바깥을 눌러 닫기와 Esc는 같은 취소 정책을 사용합니다. 창 안에서 시작한 드래그는 바깥에서 끝나도 창을 닫지 않습니다.
- 중요한 사건과 위기 최종 결정은 바깥 클릭·Esc로 넘기지 않습니다. 배경 확인을 사용하면 선택을 유지한 채 시간이 멈춥니다. 구매/연구 등 실행 확인창을 닫으면 실행을 취소하고 이전 화면으로 돌아옵니다.
- 상단 기록·설정은 다른 메뉴처럼 카테고리만 선택합니다. 그 아래 생애·추모·목표 또는 화면/소리/저장 기능을 고릅니다. 중복되던 사람들 카테고리의 추모 버튼은 기록으로 모았습니다.

## 비용·결과·전투

- 연구·건설·제작·시설 개선 등에 실제 자원 전후 수치와 조건/적용 시점, 구체적 사용 불가 사유를 표시합니다. 추가 장비를 호환 저장에서 제작할 때도 실제 대기열·작업장 조건과 표시가 일치합니다.
- 실행 확인은 얻는 것 → 자원 변화 → 조건/적용 시점 순서입니다. 연구/제작의 예약과 실제 완공·착용을 구분합니다. 작업/연구 취소는 실제 미사용 환불, 귀환은 현재 확보 물자와 남은 구급약을 미리 보여 줍니다. 의뢰 수령은 비용과 보상의 순변화를 표시합니다.
- 결과는 핵심 변화 세 개의 아이콘/증감 배지를 먼저 표시합니다. 체력·스트레스(0~100), 분야 능력(0~10), 관계(-100~100)는 이전/이후 게이지를 함께 보여 줍니다. 무한히 증가할 수 있는 자원에 임의의 최대치를 가진 게이지는 만들지 않습니다. 전체 숫자는 상세와 기록에 남습니다.
- 일반 자원·결과는 불필요한 소수점을 없애고 최대 한 자리까지 표시합니다. 내부 계산 정밀도는 유지합니다. 작업 진행은 소수 한 자리, 비율은 필요한 경우에만 소수를 사용합니다.
- 적이 오른쪽에 있을 때 아군 전방은 아군 중 오른쪽, 후방은 왼쪽에 서게 합니다. 편성 첫 사람이 전방이라는 규칙은 유지됩니다.
- 피격 반응과 적의 쓰러짐/흐려짐을 추가합니다. 전투 승리 직후 약 0.35~0.65초의 실제 시간으로 마지막 장면을 보여 줍니다. 이는 화면 연출이며 시뮬레이션·보상·저장·전투 판정을 지연시키거나 다시 계산하지 않습니다. 동작 줄이기에서는 추가 연출을 생략합니다.
- 주민 지도 갱신은 동작 설정이 켜졌을 때 최대 약 60fps를 목표로 그립니다. 이동 보간은 실제 이동 경유점을 따르고 배속에 따라 게임 시간만 진행합니다. 모든 기기에서 일정한 프레임을 보장하지는 않습니다.

## 호환과 실행

새 게임을 만들 필요가 없습니다. 이전 1.7/1.6의 물자·주민·지도·진행 중 원정/건설/방어를 유지합니다. 저장 형식 12를 유지하며 보상에 관여하지 않는 실습 이력을 선택 필드로 추가합니다. 이전 저장은 현재 사실로 완료 이력을 추론합니다. 완료한 실습은 이후 피해를 입거나 시설이 없어져도 되돌아가지 않습니다.

저장 → 게임 브라우저 탭과 검은 실행 창 모두 닫기 → 새 ZIP을 새 폴더에 전체 해제 → Start.cmd → 같은 브라우저의 이어하기 순서입니다. 주소 127.0.0.1:43187과 저장 키를 유지합니다. 설정의 저장 내보내기로 사본을 보관할 수 있습니다. 공식 Windows x64 Node 런타임을 포함하므로 인터넷·API 키·별도 Node 설치가 필요 없습니다.

## 검증 범위

- 엔진 테스트 217개: 실제 1.7/1.6 배포본 저장 이관, 실습 완료/유지, 비용 표시와 실제 실행, 예약/환불, 대기 이유, 전투 연출의 비간섭, 바닥색/말풍선 규격과 기존 사건·직업·방어·계절 규칙을 검사합니다.
- 기존 33개 종류 집계와 참조 검사. 종류와 등록된 대화 수량은 1.7과 같습니다.
- 아홉 시작 조건 × 정착/2인/3인 운영 27회로 실제 연구·건설·원정·방어·두 계절·저장을 확인합니다. polish-balance-report.md에 기록합니다.
- Chromium에서 실제 포인터·우클릭·바깥 클릭·드래그·키보드·잠금·확대·선택·실시간 펼침 유지·전투 승리와 여러 와이드 해상도를 검사합니다. 기존 도움말·지도·가족·대화·타이틀·저장·원정/건설 조작도 회귀 검사합니다.
- 압축본의 CRC, 모든 내부 파일 SHA256과 공식 런타임 체크섬을 검사하고 압축 해제한 폴더의 서버로 실행 검사를 진행합니다.
- Windows 실기 실행과 수십/수백 시간의 재미 검증은 아직 하지 못했습니다. 대화의 어색함을 전면적으로 해결했다는 업데이트도 아닙니다. 주민 개성과 관계·문장 흐름은 다음 단계에서 보완합니다.
