# 1.3.0 — 기억이 쌓이는 네 사람의 마을

약속한 3단계 업데이트입니다. 일상 관찰의 깊이를 더하면서 새로운 자원·개별 일정표·의무 대화 관리는 추가하지 않았습니다.

- 가까이 있는 주민이 성격·몸과 마음·관계·가족·식량·원정 상황에 따라 이야기합니다. 여섯 성향의 말투와 직접 쓴 15개 주제의 장면·반응을 조합합니다. 부상·갈등·식량 부족을 실제 상태로 확인하며, 도와준 적이 있는 동료에게만 과거 도움을 언급합니다. 무한 생성이나 자유 입력형 AI는 아닙니다.
- 지도 말풍선, 지도 아래 「불 곁의 목소리」, 「사람들 → 대화·기억」에서 말을 읽습니다. 말풍선은 설정에서 끌 수 있고 대화 기록은 유지됩니다. 새 메뉴 첫 안내와 설정의 다시 보기를 제공합니다.
- 동료를 골라 이야기 듣기·격려·화해를 요청하면 두 사람이 교류 장소로 걸어가 8초 동안 업무를 쉽니다. 이후 본래 역할로 돌아갑니다. 최대 90초 안에 만나지 못하거나 출정하면 취소합니다. 지친 상대는 거절하고, 갈등이 없는 사이의 화해 요청은 보상을 주지 않습니다.
- 실제 위로·화해에만 작은 스트레스·관계 변화와 전후 수치를 남깁니다. 일상 대사에는 보상이 없습니다. 같은 두 사람은 120초 간격, 주민마다 300초에 최대 세 회의 효과이며 저장 재개로 초기화되지 않습니다.
- 도움받은 사실은 기억으로 남아 후속 대화에 쓰입니다. 시설이 완성됐을 때 거점에 있던 주민만 완공 기억을 얻습니다. 원정 회고는 귀환 당시 지점·이유·체력·스트레스의 사실 기록입니다. 회고를 다시 읽어도 자원을 지급하지 않습니다.
- 8분 이후 생존자가 한 번 찾아옵니다. 잠자리·식량 12·자재 6과 성인 한 명의 계속되는 생활 식량을 확인해 직접 수락·거절합니다. 자동 합류나 시간 제한은 없습니다.
- 새 게임의 생애를 **600초/년**으로 늦췄습니다. 하루는 60초, 위기는 30분 기한과 10분 이후 조기 대응을 유지합니다. 배속은 모두 게임 시간에 적용됩니다. 성공 후 자유 생활·아이 성장·교육·성인 진로·다음 터전 계승으로 이어집니다.

## 기존 저장과 업데이트

기존 게임을 저장하고 브라우저 게임 탭과 검은 실행 창을 모두 닫으세요. 새 ZIP 전체를 새 폴더에 풀고 Start.cmd를 실행합니다. 같은 PC·브라우저·주소의 저장이 이어집니다. 먼저 설정에서 저장을 내보내 별도 보관할 수 있습니다.

저장 형식 9는 기존 주민 수·이름·외형·관계·시설·예약 작업·원정·나이·연내 진행을 보존합니다. 기존 저장은 기존 120초/년 속도를 유지합니다. 과거의 모든 사건을 새 구조 기억으로 꾸며내지 않으며 업데이트 후 실제 발생한 일부터 기록합니다. 다음 터전이나 새 게임부터 600초/년을 적용합니다. 계승자의 연내 진행은 새 속도에 비례해 변환합니다.

기존 여섯 주민을 삭제하지 않습니다. 새로운 네 명의 야영지를 시작하려면 설정에서 저장을 내보내고 새 여정을 선택하세요. 확정 전에 취소하면 이전 진행이 유지됩니다.

중요한 선택 대기 중에는 대화·합류·시간도 잠깁니다. 창을 내려 배경과 대화 기록을 살펴볼 수 있지만 결과를 바꾸는 조작은 할 수 없습니다.

## 검증과 범위

엔진 규칙, 실제 Chromium 화면 조작, 새 생애 속도의 자동 운영과 압축 해제본을 검증합니다. 자동 플레이는 기능과 고정 전략의 점검이며 사람이 느끼는 재미나 모든 편성의 승리를 보장하지 않습니다. Windows 실기 실행은 미검증입니다. 공식 Windows Node 런타임 체크섬과 ZIP·내부 파일 무결성을 확인합니다.

대화와 기억은 기록량을 제한해 오래 플레이해도 무한히 커지지 않습니다. 원정·사망 인물에게 원격 위로 효과를 주거나 계승 때 옛 상대 ID를 새 동료로 오인하지 않습니다. 실내 벽·문 편집, 전력·배관·개별 물류, 외부 생성형 AI 대화는 이번 범위에 포함하지 않습니다.
