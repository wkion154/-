# 1.9 · 주민의 개성과 관계를 연결하는 2단계

1단계의 조작·가독성 개선을 유지하고 외형, 성격, 대화, 실제 기억과 관계를 연결했습니다. 지역 재방문·연속 의뢰·후반 경제를 깊게 하는 3단계는 다음 작업입니다. 이번 기능 추가만으로 주관적 완성도 80~90점이나 수백 시간의 재미를 검증했다고 평가하지 않습니다.

## 외형과 인물 설정

- 머리 모양은 6→12종입니다. 얼굴형 4·눈썹 5·눈 5·코 4·입 5·수염 5·화장 5·점/주근깨/흉터 5·의상 6·목깃/장식 5의 열 가지 세부 축을 따로 선택합니다. 조합 수를 별도 원화나 캐릭터 수로 세지 않습니다.
- 초상화·지도·전투가 같은 얼굴과 의상 부품을 사용합니다. 새 개척단은 자체 난수로 외형과 인물 설정을 만들며, 시뮬레이션 난수·능력 주사위를 소비하지 않습니다. 시작 외형에서 수염·화장·흉터는 일부 주민에게만 나타나도록 분포를 둡니다. 모든 성별에서 원하는 외형을 고를 수 있습니다.
- 새 게임 주사위 화면과 주민 꾸미기에서 편집합니다. 적용 전에는 미리 보기이며 취소하면 현재 주민의 나이·능력·기억·관계를 바꾸지 않습니다. 개척단 잠금도 세부 외형·인물 설정을 그대로 보존합니다.
- 성별(여성/남성/논바이너리/미설정)과 연애 선호(여성/남성/성별 무관/관심 없음/미설정)를 구분합니다. 성별과 옷은 생산·공격·직업 능력 보너스를 주지 않습니다.
- 이전 주민의 성별·선호와 외형은 임의로 다시 뽑지 않습니다. 옛 여섯 항목 외형은 같은 얼굴로 그리며, 원할 때만 세부 축과 인물 설정을 추가합니다. 아이에게 연애 선호와 경계심을 편집하는 조작은 열지 않습니다.

## 대화와 기억

- 문장 뒤에 매번 성격별 상투어를 붙이던 방식을 없앴습니다. 직접 쓴 **112개 상황별 발화·응답 쌍**을 성격·생활 역할·현재 상황에 맞춰 고릅니다. 기존 기본 문장도 보조 풀로 사용하며 응답을 발화와 따로 무작위로 붙이지 않습니다. 도감에서 쌍 문장과 기본 문장을 구분해 볼 수 있습니다.
- 농사·건설·배움·휴식, 걱정·부상·갈등·친구·가족·밤·귀환 등 실제 상황을 우선합니다. 건강한 상대에게 직접 격려를 요청했을 때는 아프거나 힘들다고 단정하는 대신 가벼운 안부·응원을 고릅니다. 혼잣말에는 없는 상대의 답을 붙이지 않습니다.
- 성격은 말투 선택과 관심 주제, 자율 휴식·교류 시점에 반영됩니다. 기존 여섯 성격에도 생활 리듬을 연결했습니다. 세부 기준은 주민 설명에서 확인하며, 직접 지정한 역할과 자율 행동 끄기는 유지합니다. 기존 호환 방식은 원래 생활 기준을 유지합니다.
- 자동 대화에서 같은 발화·응답 쌍의 선택을 전역에서 12분간 쉬게 하고, 같은 주민의 주제도 기존 3분 휴지기를 둡니다. 맞는 새 말이 없으면 침묵합니다. 직접 요청한 대화는 적절한 응답을 하되 보상은 기존 간격/상한을 따릅니다. 모든 반복을 영구히 없앴다는 의미는 아닙니다.
- 실제 위로·화해·건설 목격·원정·중요한 구조·관계 결정이 기억으로 남습니다. 기억 대화에는 해당 상대와 실제로 겪은 기억을 연결하고 원문을 펼쳐 봅니다. 그 자리에 없던 주민에게 목격을 주입하지 않습니다.
- 원정 응급처치와 거점 치료에서 체력 65 미만의 동료를 도운 일은 중요한 구조 기억입니다. 같은 두 사람의 구조 기억은 5분 간격으로만 남습니다. 자신을 치료한 일을 다른 사람의 도움으로 기록하지 않습니다.
- 사소한 기억은 영향이 빨리 옅어지고, 구조·관계·상실은 오래 남습니다. 기억은 주민당 20개이며 중요한 기억을 우선 보존합니다. 같은 사실을 짧은 간격으로 중복 저장하지 않습니다. 생애와 관계 사건은 불 곁의 기록·인물의 생애·기억에도 연결합니다.
- 가족·친구 관계에서의 직접 위로와 화해는 기존처럼 실제 이동과 8초 대화, 두 사람 120초 간격/주민별 5분 3회 효과 상한을 유지합니다. 평범한 자동 잡담이 자원을 지급하지 않습니다.

## 관계의 발전과 사건

사람들 → 대화·기억에 **대화 / 관계 / 기억·원정 회고** 탭을 둡니다. 관계 카드에 상대 얼굴, 기존 신뢰(-100~100), 호감(0~100), 연인의 긴장(0~100), 함께한 시간과 연결된 기억을 함께 보여 줍니다. 신뢰와 연애 감정을 같은 수치로 취급하지 않습니다.

- **함께 시간 보내기:** 실제 만남 뒤에 기록합니다. 두 사람의 접촉은 3분 간격으로 집계하며 친밀함은 무한 클릭으로 즉시 쌓이지 않습니다. 신뢰가 있고 서로의 선호가 맞는 만남에서 호감이 자랍니다.
- **고백:** 두 사람 모두 18세 이상, 서로의 선호가 맞고, 가족이 아니며, 기존 연인이 없어야 합니다. 신뢰 25·호감 30·실제 만남 3회가 필요합니다. 조건을 갖춘 주민은 자발적으로 이야기를 꺼내거나 플레이어가 시간을 마련할 수 있습니다.
- **직접 결정:** 고백, 둘만의 경계, 질투, 이별, 재회, 개인의 경계심 돌아보기의 여섯 사건은 각 세 가지 선택을 갖습니다. 자동 모드에서도 시간을 멈추고 직접 결정합니다. 선택 전 실제 전후 수치와 개인 목표 보상까지 미리 볼 수 있습니다. 배경 확인·정보 열람은 1단계의 읽기 전용 규칙을 유지합니다.
- **거절과 재회:** 거절하면 연인으로 강제하지 않습니다. 30분간 재고백을 막고, 자동으로 같은 고백을 계속 반복하지 않습니다. 이별 뒤에는 최소 20분과 다시 쌓인 신뢰/상호 선호를 확인해 재회를 직접 요청합니다. 재회 거절 뒤에도 휴지기가 있습니다.
- **질투와 경계:** 실제로 연인이 다른 동료와 가까이 대화하는 모습을 근처에서 본 경우에만 그 사람을 언급하는 질투 사건을 만듭니다. 높은 스트레스나 원정의 부재만으로 다른 사람을 꾸며 내지 않고 경계/여유 이야기로 다룹니다. 상대를 추궁하는 선택과 감정을 차분히 이야기하는 선택의 결과가 다릅니다.
- **개인의 시선:** 기본은 성별 대신 개인으로 판단합니다. 인물 설정에서 남성 또는 여성에게 경계심이 있는 배경을 선택할 수 있고, 첫 실제 만남의 신뢰와 이후 대화에 반영됩니다. 함께 겪은 일을 돌아보는 사건에서 사과/협업의 경계/고집 중 선택합니다. 이는 해당 개인의 태도이며 특정 성별 모두의 능력·성격으로 적용하지 않습니다.
- **사별과 계승:** 연인이 떠나면 상실의 기억과 관계 기록을 남기고 새 관계를 막는 중복 연인 상태로 두지 않습니다. 계승 때는 이름이 담긴 실제 기억을 이어가며 이전 공동체의 인물 ID·연인 링크를 새 주민에게 붙이지 않습니다.
- **운영 조절:** 관계 탭에서 주민이 스스로 관계 이야기를 꺼내는 기능을 끌 수 있습니다. 꺼도 기존 연인과 기억, 직접 요청한 이야기는 유지됩니다. 원정·방어로 두 사람이 함께할 수 없거나 90초 안에 만나지 못하면 요청을 취소하고 이유를 기록합니다.

## 생활·원정과 연결되는 작은 효과

- 가까이 함께 쉬는 연인은 긴장이 30 미만일 때 스트레스 회복에 최대 8%를 더합니다. 위로/화해/구조/약속 기억과 신뢰 15 이상이 있는 가까운 동료는 최대 3%입니다. 둘은 중첩하지 않습니다.
- 원정에서 해당 기억과 신뢰를 가진 동료와 함께하면 받는 전투 스트레스 증가를 5% 완화합니다. 다른 장비·특성의 실제 감소를 계산한 뒤 적용하며 스트레스를 음수로 만들지 않습니다.
- 연애가 생산·전투의 필수 조건은 아닙니다. 기존 친구의 휴식·엄호 규칙은 유지하며, 성별로 공격·체력·일 효율을 정하지 않습니다. 출생·입양도 기존 보호자·신뢰 규칙을 유지하고 연애를 필수 조건으로 만들지 않습니다.
- 관계 사건의 신뢰 변화는 기존 개인 목표·관계 의뢰와 같은 관계 그래프를 사용합니다. 개인 목표가 완성되면 원래의 일회 보상을 적용하고 미리 보기에도 포함합니다. 능력치를 새로 굴리거나 원정 보상을 복제하지 않습니다.

## 저장·실행과 검증

현재 저장은 **형식 13**입니다. 이전 1.8/1.7/1.6 저장을 읽어 원정·건설·방어·자원·주민·외형·기억을 보존합니다. 실제 이전 1.8 배포본에서 만든 세 상태를 이관하고, 옛 얼굴 경로가 그대로 그려지는지도 검사했습니다. 새 관계 자료는 최대 512쌍, 관계 기록 24개, 대화 반복 이력 96개로 제한하고 중요한 활성 관계를 우선 보존합니다.

업데이트: 저장 → 게임 탭과 검은 실행 창 모두 닫기 → 새 ZIP을 새 폴더에 전체 해제 → Start.cmd → 같은 브라우저에서 이어하기. 주소 127.0.0.1:43187을 유지합니다. 설정의 저장 내보내기로 사본을 보관할 수 있습니다. 이전 실행 파일은 새 저장 형식을 지원하지 않습니다.

- 엔진 테스트 **241개**: 외형 각 축의 실제 그림 차이, 이전 얼굴/저장 보존, 실제 대화·기억·회복·전투 적용, 동의/거절/이별/재회/질투/경계심 선택, 미성년·가족·중복 연인 차단, 저장 복원과 손상 거부, 기존 게임 규칙을 검사합니다.
- 새 게임 세 시드에서 기본 자원과 능력을 유지하고 실제 건설·이동·격려·함께 보내는 시간으로 관계를 발전시켰습니다. 약 28게임분의 결과는 character-balance-report.md에 기록합니다. 관계 수치를 미리 지급한 브라우저 분기 검사와 구분합니다.
- 아홉 시작 조건 × 정착/2인/3인 원정 총 27회로 두 계절·연구·건설·원정·방어·저장을 검사했습니다. 결과는 character-expansion-balance-report.md입니다.
- 실제 Chromium에서 외형/성별 편집·잠금·취소·저장, 이동 후 대화, 관계 탭과 기억, 고백 중 저장 재개, 중요한 결정/배경 확인, 실제 질투의 대상, 이별, 자발적 이야기 설정과 와이드 화면을 검사합니다. 기존 도움말·지도·건설·전투·가족·합류·타이틀·원정 화면도 회귀 검사합니다.
- 압축본 CRC·내부 파일 SHA256·공식 Windows x64 Node 런타임 체크섬과 압축 해제본의 실행을 검사합니다. Windows 실기 실행은 미검증입니다.

인터넷·API·자유 입력 AI 대화 없이 동작하는 직접 쓴 유한한 대화 시스템입니다. 모든 대화가 실제 사람처럼 느껴진다는 보장이나 수십/수백 시간의 장기 플레이 검증은 아직 아닙니다. 세계의 후속 변화와 후반 경제는 3단계에서 보완합니다.
