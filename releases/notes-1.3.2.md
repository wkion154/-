# 1.3.2 — 불 곁의 기록 표시 영역 수정

오른쪽 기록 패널은 길게 늘어나지만 안쪽 목록은 고정 높이 260px에 머물러, 아래 공간이 비고 기록이 중간에서 끊긴 것처럼 보이던 문제를 수정했습니다.

- 기록 목록이 제목 아래부터 패널 하단까지 채워집니다. 긴 내용은 목록 안에서 스크롤합니다.
- 좁은 화면에서는 기록 패널이 지나치게 늘어나지 않도록 높이를 제한하되, 내부 목록은 그 공간을 모두 사용합니다.
- 저장에 보관된 최근 기록을 최대 100개까지 표시합니다. 종전에는 그중 30개만 표시했습니다. 제목 옆에 표시 건수를 알립니다. 게임은 원래 최근 100개를 보관하며, 이미 사라진 과거 기록을 복원하는 것은 아닙니다.
- 긴 문장은 줄바꿈하고 기록 영역에 키보드 포커스를 줄 수 있습니다. 화면을 다시 그려도 읽던 스크롤 위치를 유지합니다.

타이틀·네 명 주사위 생성·기존 저장과 게임 규칙은 유지합니다. 이번 수정에는 앞서 이야기한 지도 확대, 무작위 지형, 능력치 세분화, 툴팁, 그림 중심 튜토리얼 등의 기능은 포함하지 않습니다.

검증: 1280×720, 1600×900, 1920×1080, 1000×800, 640×800 화면에서 기록 목록과 패널 하단이 맞고 가로 잘림이 없음을 확인했습니다. 100개 기록의 마지막 항목 접근과 화면 재생성 후 스크롤 유지를 확인했습니다. 엔진 테스트 137개를 재검증합니다. Windows 실기 실행은 미검증입니다.

업데이트: 이전 게임에서 저장하고 게임 탭과 검은 실행 창을 닫습니다. 새 ZIP 전체를 새 폴더에 풀고 Start.cmd를 실행한 뒤 이어하기를 선택하세요.
