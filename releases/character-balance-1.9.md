# 주민·관계 2단계 실제 초기 운영 검증 · 1.9

세 시드에서 새 개척단 네 명, 기본 자원과 능력을 그대로 사용합니다. 처음 꾸미기에서 선택 가능한 성별·선호만 서로 맞추고, 두 사람은 휴식/교류, 한 사람은 농사, 한 사람은 건설로 배치합니다. 첫 밭을 실제로 짓고 150게임초마다 조건을 확인해 격려 → 함께 시간 보내기 → 고백을 요청합니다. 직접 관계 수치·기억·호감·원정 보상·식량을 지급하지 않습니다. 매번 실제 이동과 8초 대화를 기다리며, 방어·사건이 끼어들면 규칙대로 대응합니다. 중요한 고백은 두 사람이 조건을 갖춘 뒤 직접 수락합니다. 300초마다 저장을 복원합니다.
