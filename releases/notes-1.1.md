# 1.1.0 — 화면·선택·메뉴 안내 업데이트

- 상단 자원·메뉴·배속을 스크롤 중에도 고정하고 마을·원정·사람들·기록·설정으로 메뉴를 묶었습니다.
- 자원·생활·시설·장비에 SVG 아이콘, 사건에 상황 삽화와 관련 주민 얼굴을 추가했습니다.
- 메뉴 11곳의 첫 사용 안내를 세 장의 짧은 설명으로 제공합니다. 설정 → 도움말·튜토리얼에서 다시 보기·확인 이력 초기화가 가능합니다.
- 사건과 위기 최종 결정의 「배경 확인」으로 창을 내려놓고 상태를 살펴볼 수 있습니다. 이 동안 시간과 진행 변경은 잠기며, 아래 「선택 창 다시 열기」로 돌아와 결정합니다. 미결 상태는 재접속 후에도 선택을 요구합니다.
- 사건에는 실제 비용·상하한·관계·개인 목표 보상·자연사 영향을 포함한 전후 수치를 표시합니다. 선택 후 실제 변화도 확인하며 기록에 보존합니다.

## 업데이트 방법

1. 기존 게임에서 저장합니다. 안전하게 보관하려면 설정의 저장 내보내기도 사용합니다.
2. 게임 탭과 검은 실행 창을 닫습니다.
3. 새 ZIP 전체를 새 폴더에 풀고 Start.cmd를 실행합니다.
4. 같은 브라우저·주소를 사용하면 기존 저장이 이어집니다. 새 여정으로 초기화할 필요가 없습니다.

이 버전은 약속한 1단계입니다. 시작 주민 4인·주사위 생성·외형 커스터마이징·건물과 길 배치는 다음 단계이며, 현재 저장의 주민과 시설을 삭제하지 않습니다.

게임 규칙 테스트와 실제 Chromium의 기존 플레이·새 UI 시나리오를 확인합니다. Windows 런타임은 공식 체크섬으로 검증하며, 이 Linux 환경에서 Windows 실기 실행은 검증하지 못했습니다.
