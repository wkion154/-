# 잔향의 피난처 — Windows 다운로드

[윈도우 본판 ZIP 다운로드](https://github.com/wkion154/-/raw/refs/heads/downloads/releases/Hearth-of-Echoes-1.0.1-Windows-x64.zip)

1. 이전 버전을 실행 중이라면 먼저 게임에서 저장하고, 게임 탭과 검은 실행 창을 닫습니다.
2. 새 ZIP 전체를 별도 폴더에 압축 해제합니다.
3. `Start.cmd`를 더블클릭합니다. 기본 브라우저에서 게임이 열립니다.
4. 상단 **처음 하는 법**을 눌러 6단계 안내를 따라갑니다. 초기 상태라면 3단계 **추천 배치 적용**으로 역할을 정할 수 있습니다.
5. 게임 중에는 실행 창을 열어 두세요. 종료 전 게임에서 저장한 뒤 탭을 닫고 실행 창에서 Ctrl+C를 누르세요.

Windows 10/11 x64와 최신 Edge 또는 Chrome이 필요합니다. Node.js 런타임이 포함되어 별도 설치·인터넷·API 키가 필요 없습니다. 저장은 같은 PC·브라우저에 보존됩니다. 다른 PC로 옮길 때는 게임의 「화면·소리 → 저장 내보내기 / 저장 파일 불러오기」를 사용하세요.

Linux에서 게임 테스트 92개, 자동 플레이 24회, 압축 해제본의 브라우저 기능을 검증했습니다. Windows 실기 실행은 미검증입니다. 포함된 런타임의 라이선스와 빌드 정보는 ZIP 안에 있습니다. ZIP의 SHA256은 함께 제공한 `.sha256` 파일에서 확인할 수 있습니다.

## 처음에는 이렇게 해 보세요

1. **처음 하는 법 → 3단계 → 추천 배치 적용**을 누릅니다. 거점에는 치료·농사·건설 담당이 남고, 원정대는 수호자·척후병·치유사가 됩니다. 자원을 주거나 자동 출정하지는 않습니다.
2. 4단계의 **원정 편성으로 가서 직접 해 보기**를 누릅니다.
3. 오른쪽에서 **안개 숲 / 신중**을 확인하고 **원정 출발 · 식량 8**을 누릅니다.
4. 상단 **1× 또는 2×**를 누릅니다. 전투는 자동으로 진행됩니다. 갈림길에서는 **안전한 우회로**를 고릅니다.
5. 돌아온 세 명의 생활 초점을 **휴식**으로 바꾸고, 거점 치료 담당이 회복시키도록 기다립니다.

추천 배치가 비활성화되어 있다면 이미 원정에 다녀왔거나 사건·부상 등으로 초기 조건이 맞지 않는 상태입니다. 설명을 참고해 주민 상세에서 생활 초점과 원정 직업을 직접 바꿔 주세요.

기존 저장은 같은 브라우저에서 자동으로 이어집니다. **새 여정으로 초기화할 필요가 없습니다.** 업데이트 뒤 예전 화면이 보이면 기존 실행 창이 닫혔는지 확인하고 새 폴더의 Start.cmd로 다시 실행하세요.
