# 잔향의 피난처 — Windows 다운로드

## 최신판: 1.3.2 · 불 곁의 기록 표시 수정

**[윈도우 본판 ZIP 다운로드](https://github.com/wkion154/-/raw/refs/heads/downloads/releases/Hearth-of-Echoes-1.3.2-Windows-x64.zip)**

### 실행과 업데이트

1. 이전 게임을 저장하고 브라우저 게임 탭과 검은 실행 창을 모두 닫습니다.
2. 새 ZIP 전체를 새 폴더에 압축 해제합니다.
3. `Start.cmd`를 실행하면 타이틀이 열립니다.
4. **이어하기**로 기존 저장에 들어가거나 **새 게임**으로 캐릭터 네 명을 먼저 뽑습니다.

Windows 10/11 x64와 최신 Edge 또는 Chrome용입니다. Node.js 런타임이 포함되어 별도 설치·인터넷·API 키가 필요 없습니다. 게임 중 실행 창을 열어 두세요. Windows 실기 실행은 미검증입니다.

### 이번 수정

오른쪽 「불 곁의 기록」의 바깥 패널만 길어지고 안쪽 목록은 260px로 고정돼 아래 공간이 비던 문제를 수정했습니다.

- 기록 목록이 제목 아래부터 패널 하단까지 채워집니다. 긴 기록은 내부 스크롤로 봅니다.
- 보관된 최근 기록을 최대 100개까지 표시하고 제목 옆에 표시 건수를 알립니다. 이전에는 30개만 표시했습니다.
- 긴 문장을 줄바꿈하고 키보드로도 목록을 스크롤할 수 있습니다. 화면을 다시 그려도 읽던 스크롤 위치를 유지합니다.
- 작은 화면에서는 패널 높이를 제한하면서 내부 공간을 채웁니다.

타이틀의 **이어하기 / 새 게임 / 설정**, 네 명 주사위·외형 생성, 기존 저장과 게임 규칙은 그대로 이어집니다.

저장은 같은 PC·브라우저에 보존됩니다. 다른 PC나 브라우저로 옮길 때는 저장 내보내기·불러오기를 사용하세요.
