# 잔향의 피난처 — Windows 다운로드

[윈도우 본판 ZIP 다운로드](https://github.com/wkion154/-/raw/refs/heads/downloads/releases/Hearth-of-Echoes-1.0.0-Windows-x64.zip)

1. ZIP 전체를 압축 해제합니다.
2. `Start.cmd`를 더블클릭합니다. 기본 브라우저에서 게임이 열립니다.
3. 게임 중에는 실행 창을 열어 두세요. 종료 전 게임에서 저장한 뒤 탭을 닫고 실행 창에서 Ctrl+C를 누르세요.

Windows 10/11 x64와 최신 Edge 또는 Chrome이 필요합니다. Node.js 런타임이 포함되어 별도 설치·인터넷·API 키가 필요 없습니다. 저장은 같은 PC·브라우저에 보존됩니다. 다른 PC로 옮길 때는 게임의 「화면·소리 → 저장 내보내기 / 저장 파일 불러오기」를 사용하세요.

Linux에서 게임 테스트 89개, 자동 플레이 24회, 압축 해제본의 브라우저 기능을 검증했습니다. Windows 실기 실행은 미검증입니다. 포함된 런타임의 라이선스와 빌드 정보는 ZIP 안에 있습니다. ZIP의 SHA256은 함께 제공한 `.sha256` 파일에서 확인할 수 있습니다.
