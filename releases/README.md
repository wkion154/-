# 잔향의 피난처 — Windows 다운로드

## 최신판: 1.3.1 · 타이틀에서 고르는 새 게임과 이어하기

**[윈도우 본판 ZIP 다운로드](https://github.com/wkion154/-/raw/refs/heads/downloads/releases/Hearth-of-Echoes-1.3.1-Windows-x64.zip)**

### 실행과 업데이트

1. 이전 게임을 저장하고 브라우저 게임 탭과 검은 실행 창을 모두 닫습니다.
2. 새 ZIP 전체를 새 폴더에 압축 해제합니다.
3. `Start.cmd`를 실행하면 타이틀이 열립니다.
4. **이어하기**로 기존 저장에 들어가거나 **새 게임**으로 캐릭터 네 명을 먼저 뽑습니다.

Windows 10/11 x64와 최신 Edge 또는 Chrome용입니다. Node.js 런타임이 포함되어 별도 설치·인터넷·API 키가 필요 없습니다. 게임 중 실행 창을 열어 두세요. Windows 실기 실행은 미검증입니다.

### 이번 수정

- **매번 타이틀에서 시작**합니다. 이어하기를 누르기 전에는 저장된 배속으로도 시간이 흐르지 않습니다.
- **새 게임 → 주사위로 네 명 뽑기 → 외형 꾸미기 → 확정 → 마을 시작**으로 연결됩니다. 고르던 구성도 복원하며, 취소·Esc로 돌아갈 수 있습니다.
- **설정 창 안에 「새 게임 · 네 명 뽑기」「타이틀 화면으로」**를 추가했습니다. 종전에는 상단 설정 탭 아래에만 새 여정 버튼이 있었습니다.
- 기존 저장은 네 명을 확정하기 전까지 유지됩니다. 보관하려면 먼저 **설정 → 저장 내보내기**를 사용하세요. 기존 여섯 주민도 이어하기로 유지합니다.
- 게임 중 타이틀로 돌아가면 저장합니다. 원정·공사·미결 선택도 보존하며, 다시 이어하기를 누른 뒤 진행합니다.
- 타이틀의 단축키나 자동 저장이 임시 게임으로 기존 저장을 덮지 않습니다. 저장이 없거나 손상됐다면 이어하기를 잠급니다.

성격·상황·기억에 따른 대화, 위로·화해·회고, 선택하는 생존자 합류와 4인 주사위·꾸미기·직접 건설·길·2/3인 원정 기능을 포함합니다. 새 게임은 생애 1년이 게임 시간 10분이며, 기존 저장의 나이와 2분/년 속도는 유지합니다. 대화는 직접 쓴 장면과 실제 상태를 조합해 오프라인으로 동작합니다.

저장은 같은 PC·브라우저에 보존됩니다. 다른 PC나 브라우저로 옮길 때는 저장 내보내기·불러오기를 사용하세요.

검증: 기존 규칙 테스트 **137개**와 타이틀·새 게임·취소·설정·저장 보호·선택 대기·와이드 해상도의 실제 브라우저 검증을 수행했습니다. 공식 런타임 체크섬과 ZIP·내부 파일 무결성을 확인하고 SHA256 파일을 함께 제공합니다. 시뮬레이션 규칙은 1.3과 동일하며 1.3의 자동 운영 보고서는 배포본에 포함합니다.
