# 1.3.1 — 타이틀에서 시작하고 네 명을 직접 뽑기

게임을 다시 켜면 저장된 마을로 바로 들어가던 흐름을 바꿨습니다. 매번 시작 화면에서 이어하기·새 게임·설정을 고릅니다.

- **이어하기**: 저장된 여정·날짜·주민 수를 확인하고 들어갑니다. 타이틀에서는 시간이 흐르지 않고 저장된 배속도 진행되지 않습니다. 저장이 없거나 손상됐다면 이어하기를 잠급니다.
- **새 게임**: 주사위·잠금·외형 편집으로 개척단 네 명을 먼저 고릅니다. 이전에 고르던 구성도 복원합니다. 확정하기 전에는 기존 게임과 저장을 교체하지 않으며, 취소·Esc로 돌아올 수 있습니다.
- **설정**: 화면·소리·저장 불러오기와 함께 「새 게임 · 네 명 뽑기」「타이틀 화면으로」 버튼을 설정 창 안에도 표시합니다. 종전의 새 여정 버튼은 상단 설정 탭 아래에만 있었습니다.
- 게임 중 타이틀로 돌아가면 현재 진행을 저장합니다. 미결 사건·위기 선택과 원정·공사도 보존하고, 이어하기를 선택한 뒤 확인합니다. 중요한 선택을 타이틀로 우회해 자동 처리하지 않습니다.
- 시작 화면에서 S·배속·Space를 눌러 임시 게임을 저장하거나 시간을 진행할 수 없습니다. 손상된 저장은 명시적 새 게임 확정이나 불러오기 전까지 보존합니다.

기존 저장 형식은 9로 유지하며 주민·시설·원정·기억을 변환하거나 초기화하지 않습니다. 새 캐릭터를 뽑으려는 경우 「새 게임」을 선택하세요.

업데이트: 이전 게임에서 저장하고 브라우저 탭과 검은 실행 창을 모두 닫습니다. 새 ZIP 전체를 새 폴더에 압축 해제하고 Start.cmd를 실행하세요. 같은 PC·브라우저에서는 타이틀의 이어하기로 기존 저장에 들어갑니다. Windows 실기 실행은 미검증입니다.
